09月25周五

北京 → 新乡｜二胖 + 会合

长途驾驶为主，下午到新乡后集中逛二胖。

约650–670km含补能约9–10小时二胖：免费
  1. 06:30

    北京满电出发

    沿京港澳高速南下，按实际续航安排2–3次补能。

  2. 15:30–16:30

    预计抵达新乡

    先完成新乡东站会合，再前往二胖。

  3. 17:00

    胖东来生活广场（二胖）

    地址：新乡市卫滨区健康路31号。先逛服装、鞋靴，再逛超市、生鲜和熟食。

    门票：免费。
  4. 20:00后

    晚饭 / 回酒店

    二胖或周边吃饭后，回银星酒店休息。

银星酒店（中心医院胖东来店）
09月26周六

新乡 → 洛阳｜洛阳博物馆 + 西工小街 + 应天门

下午洛博，晚上西工小街和应天门夜景。

约190km / 约2.5小时酒店→洛博约3km洛阳博物馆：免费
  1. 08:00

    新乡出发

    早餐后退房前往洛阳。

  2. 中午

    牛肉汤 + 入住 / 寄存

    推荐牛肉汤配烧饼或饼丝，之后前往洛悦春梅酒店。

  3. 13:30

    洛阳博物馆

    重点看河洛文明、唐三彩和珍宝类展陈，提前实名预约。

    门票：免费，实名预约入馆。
  4. 17:30

    西工小街晚饭

    推荐小街锅贴，搭配浆面条、馄饨或粥。

    酒店→西工小街：约9km / 20–25分钟西工小街→应天门：约3km / 10–15分钟
  5. 19:00

    应天门 + 明堂天堂外围

    以建筑夜景和散步拍照为主。

    门票：外围夜景免费；如入内，以当天官方票价为准。
  6. 21:00

    回洛悦春梅酒店

    连住两晚。

洛悦春梅酒店（洛阳博物馆店）
09月27周日

洛阳｜龙门石窟 + 老城慢逛

上午龙门，下午休息，傍晚老城。

酒店→龙门约13km / 25–30分钟龙门石窟：90元 / 半价45元
  1. 07:00

    早餐后去龙门石窟

    停车优先导航“龙门石窟西北服务区停车场”。

  2. 08:30

    龙门石窟

    西北服务区 → 大石门 → 宾阳三洞 → 万佛洞 → 莲花洞 → 奉先寺 / 卢舍那大佛 → 漫水桥 → 礼佛台。

    门票：全价90元，半价45元；景交车单程10元。
  3. 12:30

    午饭 + 午休

    返市区方向顺路吃饭，时间合适回酒店午休。

  4. 15:30

    丽景门—十字街 / 洛邑古城

    以街区慢逛和晚饭为主。

    门票：丽景门外观、老城街区、洛邑古城常规游览免费；内部展馆或体验另计。
洛悦春梅酒店（洛阳博物馆店）
09月28周一

洛阳 → 开封｜老城 + 夜市

上午换城，下午轻松逛老城，晚上夜市。

约193km / 约2小时45分酒店→鼓楼约6–7km开封老城街区：免费
  1. 09:00

    洛阳出发

    从洛悦春梅酒店退房后直接去开封。

  2. 中午

    入住丽呈睿轩酒店

    9/28入住，9/30退房，共2晚。

  3. 14:00

    书店街 / 鼓楼 / 包公湖周边

    以街区慢逛为主。

    门票：街区和包公湖周边散步免费；收费景点另购票。
  4. 18:00

    夜市

    推荐西司夜市或鼓楼一带，吃炒凉粉、杏仁茶、锅贴、灌汤包等。

丽呈睿轩酒店（汴梁小宋城店）
09月29周二

开封｜万岁山完整一天 + 夜场

先约三打祝家庄和打铁花，空档看王婆说媒、逛街区。

酒店→万岁山约8–10km / 20–25分钟成人票100元 / 优待票50元
  1. 开园前20–30分

    到入口排队，准备入园

    前一晚在“万岁山武侠城”公众号查看节目单和地图。若当天08:00开园，就按07:40左右到入口，另外预留停车、步行时间。

    9/29正式场次尚未确认，开场与放票以当天为准；下面的提前量是建议，不保证有座。
  2. 入园立即

    先预约两场大秀

    四人检票入园后，打开“万岁山武侠城”公众号 → 侠客服务 → 演出预约，分别预约《三打祝家庄》、沙场《打铁花》，确认四人各有预约和座位号。

    未放票按页面时间等候，满场就换场次；现场排队不能代替预约。预约流程参考
  3. 按预约场次

    三打祝家庄｜城寨沙场

    看《水浒传》题材的武打、攻防实景大戏。建议提前30–40分钟到预约页指定入口，凭预约对号入座；票面有更早要求则按票面执行。

  4. 两场之间

    王婆说媒 + 街区互动 + 午休

    王婆说媒看主持人与游客的幽默互动，按地图找舞台，建议提前20–30分钟到。街区可和江湖人物演员聊天、接任务、合影；午饭后留30–60分钟坐下休息。

  5. 傍晚 / 夜场

    吃晚饭，再看沙场打铁花

    17:00–18:00左右吃晚饭，再按预约去城寨沙场看铁水击打成漫天金色火花。建议提前30–40分钟到夜场入口，凭该场预约入座，演出以当天安排为准。

  6. 夜场后

    回丽呈睿轩酒店，给车补电

    看完回酒店住第二晚，顺便补电，确认次日退房和行李寄存。

    门票：成人票100元，优待票50元；资格及预约规则以景区当日公示为准。
丽呈睿轩酒店（汴梁小宋城店）
09月30周三

开封｜清明上河园 → 夜间返临沂

重点看马战、水战，杨门女将可选；看完夜景返临沂。

酒店→清园约7–9km / 20–25分钟成人票120元 / 优待票60元开封→临沂约443km / 约6小时
  1. 07:30–08:30

    退房，08:30左右到迎宾门

    早餐后退房，行李装车或寄存，出发前补足电。按09:00开园参考，08:30左右到迎宾门排队；入园先查节目单，若大演出需扫码预约就先预约。

    以下场次仅为参考，9/30正式排期尚未确认。以当天节目单调整排队时间，提前到场不保证有座。查看在线节目表
    门票：成人票120元，优待票60元；《大宋·东京梦华》另售演出票。
  2. 09:30–09:45

    岳飞枪挑小梁王｜马战

    去大宋·校场，看骑手马背对战和武打。参考10:30开演，建议提前45–60分钟到观众入口排队，途中拍照顺路即可。

  3. 11:30–13:00

    午饭 + 午休

    园内就近吃饭，留45–60分钟休息，驾驶员优先补觉。之后向九龙桥方向走，沿途短场顺路看。

  4. 14:00–14:15

    大宋·东京保卫战｜水战

    去九龙桥西南水面观演区，看战船对战和声光特效。参考15:00开演，建议提前45–60分钟到指定入口排队。

  5. 16:00–17:30

    逛宋代街区，提前吃晚饭

    水战结束后慢逛、休息、吃晚饭。体力允许再加看下一场，累了就继续休息。

  6. 17:40–17:50

    可选：大宋·杨门女将

    去节目单标注的《东京梦华》主舞台，本场看杨家女将题材演出。参考18:20开演，建议提前30–40分钟到；这是加看项。

  7. 19:00–21:00

    看夜景，取车返临沂

    19:00–20:00看虹桥与河岸夜景；20:00–20:15往出口走，取车、取行李后，争取20:30–21:00启程。另购晚场演出会推迟返程。

    约6小时车程不含充电、堵车和休息；补能另留时间，轮换驾驶，困了就进服务区休息。
