9/25
周五

北京 → 新乡｜新乡会合 + 二胖

北京到新乡约650–670km；纯驾驶约7–8小时，含充电、吃饭和休息按9–10小时准备。

06:30

北京满电出发

沿京港澳高速南下。元PLUS 430km版本按实际续航安排2–3次补能，服务区是否排队以当天为准。

途中

充电 + 午饭

不要把某一个充电站锁死，剩余电量和空桩情况合适就补。午饭那次可以顺便多充一会。

15:30–16:30

预计抵达新乡

按正常路况和2–3次补能估算，06:30出发大约这个时间段进入新乡；节前堵车时适当顺延。

下午

新乡东站会合

济南出发的同行人直接坐高铁到新乡东站，你到新乡后再会合，不再中途去石家庄或邯郸接人。

17:00左右

胖东来生活广场（二胖）

地址：新乡市卫滨区健康路31号。重点逛服装、鞋靴和超市，建议预留约3小时。

顺序建议：先逛服装 → 再逛超市、生鲜和熟食，避免拎着食品继续逛。
20:00–21:00

晚饭 / 回酒店

可以在二胖解决一部分吃饭和采购，再回银星酒店（中心医院胖东来店）休息。

9/26
周六

新乡 → 洛阳｜龙门石窟 + 夜游

上午从新乡出发，中午到洛阳，下午重点龙门石窟。

08:00

新乡出发

睡够再走，抵达后先到汉庭洛阳市政府宝龙广场店寄存行李或办理入住。

11:30

洛阳牛肉汤

牛肉汤 + 烧饼/饼丝；不安排羊肉汤，也不吃洛阳水席。
13:00

龙门石窟

西北服务区停车 → 大石门 → 西山石窟 → 奉先寺 / 卢舍那大佛 → 漫水桥 → 礼佛台 → 返回。

18:00

西工小街晚饭

小街锅贴 + 浆面条 / 馄饨 / 小米粥。

19:30

应天门 + 明堂天堂外围

以夜景散步为主，还有体力再去洛邑古城。

9/27
周日

洛阳 ⇄ 老君山｜当天往返

两级索道都坐，不住栾川，不等金顶亮灯。

06:15

洛阳满电出发

目标08:30前后到老君山。

09:00

两级索道上山

一级索道 + 二级索道，把体力留给十里画屏。

09:30

核心路线

二级索道 → 十里画屏 → 马鬃岭 → 南天门 → 金顶道观群。

14:30

开始返程

14:30–15:00往索道方向返回，目标16:30前开车离开景区。

19:00左右

回到洛阳

当晚不再排景点，直接吃饭休息。

9/28
周一

洛阳 → 开封｜轻松半日

睡够再出发，下午博物馆或老城，晚上夜市。

09:00

洛阳出发

退房后直接开往开封。

中午

酒店寄存行李 / 入住

开封酒店尚未最终确定，计划9/28、9/29、9/30连住三晚。

14:00

开封博物馆

约上就去；预约不到就改为书店街、鼓楼、包公湖周边。

18:00

老城 + 夜市

西司夜市或鼓楼一带，炒凉粉、杏仁茶、锅贴、灌汤包等。

9/29
周二

开封｜万岁山完整一天

不和清明上河园拼一天，把节目和夜场完整体验。

开园前

提前到景区

入园第一件事看当天节目单和预约规则。

全天

围绕大型演出安排路线

午饭晚饭尽量园内解决，不出园折腾。

夜场后

回酒店

不再追加其他景点。

9/30
周三

开封｜清明上河园完整一天

北宋市井、建筑、演出和夜景慢慢看。

上午

开园后入园

先看当天演出时间表，再按场次串联园区。

白天

市井 + 建筑 + 演出

不用赶场，累了就休息。

晚上

夜景后回酒店

回酒店后把元PLUS充足电，为10月1日返程准备。

10/1
周四

开封 → 临沂｜国庆返程

重点避堵和充电排队。

06:00

尽早离开开封

前一晚尽量充满电，早餐不为名店绕路。

途中

灵活补电

根据空桩和剩余续航调整，不锁死服务区。
