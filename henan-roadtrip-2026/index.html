河南自驾最终详细行程

住宿已确定：洛阳2晚住汉庭酒店（洛阳市政府宝龙广场店）；9/27住栾川山合友酒店（老君山凤凰天街店）；许昌住三国大酒店（胖东来时代广场曹魏古城店）。
餐饮原则：优先吃真正有当地代表性的店和小吃，允许为值得吃的店多开10–20分钟；如果一家店会让当天绕很大一圈或明显影响景点节奏，再放弃。明确不安排洛阳水席，也不安排羊肉汤。
已删除景点：白马寺、九洲池、大相国寺、天界山、宝泉。

9月25日｜北京 → 洛阳

06:00左右北京满电出发，约798km。当天不安排景点，按150–180km一个补能观察点规划，预计4次左右快充。

到洛阳后：直接入住汉庭酒店（洛阳市政府宝龙广场店）。这天最重要的是休息，不为了吃饭再进老城区；酒店周边吃一顿热饭即可，把真正的洛阳特色留到第二天。

9月26日｜龙门石窟 + 洛阳夜景

06:40–07:20｜早餐：兄弟俩老李家牛肉汤（洛龙店）

羊肉汤取消，改喝洛阳牛肉汤。优先导航“兄弟俩老李家牛肉汤（洛龙区通济街/旗舰店）”。这家从1993年前后做到现在，是洛阳本地很有代表性的牛肉汤馆；洛龙店离你住的汉庭和前往龙门石窟的方向都更合适，不需要为了老店跨城。

建议点法：牛肉汤 + 饼丝/烧饼；想吃扎实一点就加一份牛肉或牛血。洛阳牛肉汤通常先给原汤，盐和辣椒自己调，第一口可以先喝原汤再调味。

07:30左右｜自驾去龙门石窟，停车位置写死

导航目的地优先设：“龙门石窟西北服务区停车场”或“龙门石窟西北服务区”。
为什么停这里：西北服务区停车规模大，且比东北服务区距检票口更近。你们想省体力，优先西北。
节假日例外：如果现场交警把车流分到东北服务区，不要逆行找西北，按分流停车，再坐电瓶车。

08:00–11:30｜从哪个门进、里面怎么走

停车后：跟指示牌往“大石门 / 西山石窟入口”走。西北服务区到检票口不想走可坐电瓶车，单程10元/人。

省体力精华线：西北服务区停车场 → 大石门检票 → 西山石窟北端 → 潜溪寺 → 宾阳三洞 → 摩崖三佛龛 → 万佛洞 → 莲花洞 → 奉先寺 / 卢舍那大佛 → 古阳洞、药方洞（体力允许再看） → 西山南门 → 漫水桥 → 东岸礼佛台拍西山全景。

到礼佛台后不要硬爬东山。重点是西山和卢舍那大佛。礼佛台拍完后，询问现场工作人员当天返西北服务区的电瓶车站点；电瓶车线路会根据客流调整。若当日不能直接返回，就继续按工作人员指引到白园停车场/龙门桥一侧再换返程车。

非常重要：景区实行单向游览，西山石窟走出闸口后不要想着原路返回，所以奉先寺、卢舍那等想拍的内容要在出西山前拍完。

门票：全价90元；持教师资格证 + 本人身份证的外地人民教师按当前官方政策可购半价票45元。9/26属于假期客流期，提前实名购票。

11:45–14:30｜午饭 + 回酒店休息

午饭不追名店，回洛龙区后吃烩面、锅贴、普通牛肉汤都行，重点是尽快回汉庭休息。晚上再专门安排一顿更有洛阳代表性的。

17:30–18:40｜晚饭：西工小街锅贴

这顿保留小街锅贴。它是洛阳本地很有代表性的老味道，锅贴底脆、肉馅多，可搭浆面条 / 馄饨 / 小米粥。建议导航“西工饭庄小街锅贴（西工小街/房地产大厦附近门店）”，当日看哪家营业正常、排队较短就去哪家。

这顿会比在酒店旁边吃稍微绕一点，但它更符合你“想吃到当地好吃的”这个目标，而且吃完继续去应天门属于同一方向，不算无效绕路。

19:20以后｜应天门夜景

看应天门北广场、明堂天堂外围；体力够再去洛邑古城或丽景门二选一。晚上如果还想补一口当地小吃，可以喝杏仁茶、吃涮牛肚，但不要再安排正餐。

9月27日｜洛阳 → 老君山 → 栾川

07:00从洛阳满电出发，约150–170km，预计09:00左右到老君山。

索道方案

  • 老君山门票：100元；教师资格证 + 身份证半价50元
  • 一级索道往返：130元，建议必坐
  • 二级索道往返：80元，想省体力建议坐
一级索道 → 二级索道 → 十里画屏 → 马鬃岭 → 南天门 → 金顶道观群 → 等亮灯 → 两级索道下山

9/26晚再次核对9/27当天亮灯时间和索道运营公告。

下山后住宿：栾川山合友酒店

酒店全名：栾川山合友酒店（老君山凤凰天街店），地址栾川滨河北路1号。距老君山景区不远，有免费停车场和充电车位。下山后直接开去酒店，不住七里坪。

晚饭：优先吃栾川本地菜

首选大有自在小馆（凤凰天街C栋2楼）。这家比单纯“离酒店最近”更值得去，建议两个人从以下里面选2–3样：栾川豆腐、橡子面饺、凉拌笋片、黄精归元鸡。其中栾川豆腐和橡子面饺更有本地辨识度。

如果下山晚、排队太长，就改伊家厨庄（凤凰天街B栋对面），可点芝麻叶糊涂面、食神豆腐等。两家都在凤凰天街，属于“为了吃得更好稍微走一点”，但不会严重影响休息。

晚上尽量把车补到90%–100%。

9月28日｜栾川 → 许昌胖东来

07:30酒店早餐，08:00左右从山合友酒店出发。栾川到许昌约295km，中途安排1次快充 + 简餐。

13:00左右到许昌，入住三国大酒店（胖东来时代广场曹魏古城店），七一路636号；免费停车、有充电位，距时代广场很近。

14:00–17:00｜胖东来大众服饰

地址：颍昌路838号。重点看鞋、男装/女装和服饰。

17:10–20:30｜胖东来时代广场

地址：七一路277号。继续逛百货、超市、熟食/烘焙。这里不把“商场吃饭”当成许昌代表正餐，但可以顺便买胖东来自营的熟食、烘焙、香辣牛肉条、甜品，这是来许昌值得体验的一部分。

晚上逛完就回三国大酒店，不再加一顿大餐，因为第二天早餐安排真正的许昌本地味。

9月29日｜许昌本地早餐 → 开封

07:00｜许昌早餐：丁小旭胡辣汤

这顿专门为了当地早餐允许小绕路。导航“丁小旭胡辣汤（碧水名郡店）”，建议点优质肉胡辣汤 + 水煎包 / 葱油饼。它属于本地早餐店，不是游客型大餐馆，营业很早，吃完再退房/出发正合适。

如果当天起晚了，为了不影响开封行程就取消，酒店周边吃胡辣汤 + 水煎包即可。

08:30左右｜许昌 → 开封

约129km，预计10:30左右到开封。周二胖东来多数门店闭店，不再安排购物。

11:30｜午饭：邢家锅贴老店·非遗·开封菜

午饭从原来的“随便吃灌汤包”升级为邢家锅贴老店（大梁门总店）。建议点鲜肉韭黄锅贴 + 炒凉粉 + 桶子鸡，两个人不要再点一大条鲤鱼焙面，容易吃撑。人均约50–60元。这顿会比直接在开封府门口吃稍微绕一点，但更值得。

13:30–16:30｜开封府

成人票参考65元。下午挑2–3场演出即可，不用全追。

19:00｜西司广场夜市

晚饭继续保留西司广场夜市，因为这里相比纯游客夜市更适合吃地道小吃。两个人按“小份多样”来：羊肉炕馍、炒凉粉、杏仁茶、四味菜/羊肉汤、涮牛肚，不要每样都买大份。

开封连续住两晚，优先万岁山—东京大道附近，免费停车和充电方便优先。

9月30日｜万岁山武侠城完整一天

07:45–08:00左右到景区。入园第一件事看当天节目单，优先锁定《三打祝家庄》《打铁花》等热门节目；必须以当天小程序预约规则为准。

午饭、晚饭都在园内解决，这天不为了吃饭出园折腾。前一天已经把开封当地吃得比较完整了。晚上玩到约21:30–22:00，回酒店后把车充到100%。

10月1日｜开封 → 临沂

06:00满电出发，约440km。国庆首日高速免费但可能拥堵，这天不再专门绕路吃早餐，简单吃完直接走；按实时空桩安排2次快充。

七、费用估算

原两人总预算仍按约5100–6100元估算，购物另算。教师资格证按人数节省：1人持证约再省95元，2人都持证约再省190元。餐饮因为现在改为“当地好吃优先”，建议两人7天餐饮预算按1600–2200元更舒服一些。

这版核心：景点不再加；住宿按你确认的酒店走；龙门石窟停车和入口写清；洛阳早餐改成牛肉汤，不再安排羊肉汤。
