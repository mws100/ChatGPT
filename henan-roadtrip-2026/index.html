9/25
周五

北京 → 新乡｜新乡会合 + 二胖

北京到新乡约650–670km；纯驾驶约7–8小时，含充电、吃饭和休息按9–10小时准备。

06:30

北京满电出发

沿京港澳高速南下。元PLUS 430km版本按实际续航安排2–3次补能，服务区是否排队以当天为准。

途中

充电 + 午饭

不要把某一个充电站锁死，剩余电量和空桩情况合适就补。午饭那次可以顺便多充一会。

15:30–16:30

预计抵达新乡

按正常路况和2–3次补能估算，06:30出发大约这个时间段进入新乡；节前堵车时适当顺延。

下午

新乡东站会合

济南出发的同行人直接坐高铁到新乡东站，你到新乡后再会合，不再中途去石家庄或邯郸接人。

17:00左右

胖东来生活广场（二胖）

地址：新乡市卫滨区健康路31号。重点逛服装、鞋靴和超市，建议预留约3小时。

顺序建议：先逛服装 → 再逛超市、生鲜和熟食，避免拎着食品继续逛。
20:00–21:00

晚饭 / 回酒店

可以在二胖解决一部分吃饭和采购，再回银星酒店（中心医院胖东来店）休息。

9/26
周六

新乡 → 洛阳｜博物馆 + 应天门夜景

第一天上午仍在赶路，下午以室内参观为主；龙门石窟移到次日上午。以下时间为计划安排，不是实时导航或已预约时段。

08:00

新乡银星酒店出发

早餐后退房前往洛阳，按11:00–12:00抵达预留时间；实际到达以导航、休息和交通情况为准。当天不安排远郊景点。

中午

牛肉汤 + 入住 / 寄存行李

在行驶方向上吃牛肉汤配烧饼或饼丝，不吃水席、羊肉汤。酒店顺路就寄存行李，不顺路则参观后办理入住，避免先往返跑一趟。

13:30

洛阳博物馆｜约上才去，预留约2.5小时

建议13:30–16:00参观，重点看河洛文明、唐三彩和珍宝类展陈，不追求所有展厅。提前从洛阳博物馆官方微信公众号预约，四人均按对应身份要求预约并带证件原件。

官网常规开放时间为09:00–19:00，18:30停止入馆。当天实际安排以馆方公告和预约页面为准。约不到9/26但约到9/27下午，可把博物馆移到次日下午、缩短老城游览；两天都约不上，就休息和慢逛，不影响主线。
16:00

留出交通、入住和短休时间

到17:30前不再追加景点。根据最终酒店位置安排入住或休息，然后进入西工片区吃晚饭。

17:30

西工小街晚饭

安排小街锅贴，搭配浆面条、馄饨或粥。饭后直接接应天门夜游，不再先回酒店再出门。
19:00

应天门 + 明堂天堂外围

建议19:00–20:30看建筑夜景、散步拍照，默认不购买登楼、演艺套票；需要入内再核对票种。灯光秀与演出不锁定场次，以当天官方安排为准。洛邑古城留作次日老城备选，不在今晚继续赶。

21:00

回洛阳住处休息

9/26入住、9/28退房，连住两晚。按两间双床房、每人一张独立床和一床被子筛选；原选熙桐民宿，新酒店未确认前不视为已更换或已取消订单。

9/27
周日

洛阳｜龙门石窟 + 老城慢逛

取消老君山、索道和山路往返。上午集中看石窟，午后留休息，傍晚只选一条老城路线。

07:00

早餐后去龙门石窟

在住处附近吃早餐，按08:00–08:30到景区停车场规划出发。不要为了早餐名店绕路；具体出发时间等酒店确定后按导航调整。

08:30

龙门石窟｜白天精华，预留3–4小时

停车导航优先设“龙门石窟西北服务区停车场”；遇分流则服从现场指引。官网显示08:00开始售票/入园，西北服务区到石窟检票处步行约20分钟，可乘景交车。

建议路线：西北服务区 → 大石门 / 西山入口 → 宾阳三洞 → 万佛洞 → 莲花洞 → 奉先寺 / 卢舍那大佛 → 西山南端 → 漫水桥 → 礼佛台。以西山精华为主，不强行爬东山、香山寺或逛完白园；返回停车场前问工作人员景交车站点和方向，不默认能逆向穿回西山。
12:30

午饭 + 午休

龙门游览结束后往市区方向走，顺路吃午饭，留出约1小时坐下来休息。酒店顺路就午休，否则在后续游览片区休息，不专门跨城来回取放行李。

15:30

老城二选一｜默认丽景门—十字街

主线：丽景门外观 → 东西大街慢逛 → 十字街晚饭，建议15:30–19:00完成。更想拍照看夜景，则用17:00–19:00洛邑古城替换这条路线；核对当天预约、开放和限流信息，不把两条路线都列成必去。

四人分着点牛肉类、锅贴、面食等，避开羊肉汤、水席。老城一片停一次车，再步行或打车衔接，不为每个小景点反复挪车。
19:00

结束游览｜保留火车衔接机动

你之前提过晚22:00火车，本版不默认取消：如果仍需赶车或送站，19:00后不再加景点，留出取行李、接送和安检时间，建议20:30前到票面出发站。洛阳站与洛阳龙门站要分清，车次与车站尚未确认。

不赶车的同行人返回洛阳住处休息；车辆按次日行程准备好电量，不需要再为往返山路专门补能。
9/28
周一

洛阳 → 开封｜轻松半日

早餐后出发，下午以老城休闲为主，晚上夜市。

09:00

洛阳出发

从洛阳住处退房后直接开往开封，不再返回景区取行李。

中午

酒店寄存行李 / 入住

开封酒店尚未最终确定，计划9/28、9/29、9/30连住三晚。

14:00

开封老城｜书店街、鼓楼或包公湖周边

9/28是周一，开封博物馆按常规周一闭馆，不再列为当天必去。只有馆方明确临时开放且预约成功，才用博物馆替换老城安排；否则按老城与夜市主线走。

18:00

老城 + 夜市

西司夜市或鼓楼一带，炒凉粉、杏仁茶、锅贴、灌汤包等。

9/29
周二

开园前

全天

夜场后

市井 + 建筑 + 演出

晚上
