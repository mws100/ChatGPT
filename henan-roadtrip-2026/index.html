先记住：9月24日早7点，预约9月26日洛阳博物馆。
以下均为北京时间，核对日期2026/9/18。区分“已查到的规则”“建议准备时间”和“待确认”，不是已订票清单；假期新公告优先。

    洛阳博物馆 · 9/26下午现有规则推算

    通过“洛阳博物馆”官方微信公众号预约。按提前2天、早7点放票的现有公开规则，9/24约9/26；建议06:55就绪。9/23先查中秋公告，如预约窗口调整，以馆方页面为准。

    依据：大象新闻2026/2/11预约时间表；2026/5/2馆方预约渠道提醒。这不是中秋专属开票公告。

  2. 9/20–9/24提前7–3天 · 建议
    龙门石窟 · 9/27上午准备建议

    9/20开始查看，争取9/24前完成9/27的实名分时购票；日期未开放则按系统提示办理。渠道：“龙门石窟”或“龙门石窟官微”微信公众号。未确认统一放票时刻，不把网上的“几点抢票”写成规则。

    景区官网实名购票须知 · 查看当天路线

  3. 9/24、9/26提前3天初查 · 前1天复核

    17:30–20:30，明确安排洛邑古城。不以“现场肯定能进”作为前提。

  4. 9/28入园前1天 · 建议购票

    从“万岁山武侠城”官方微信公众号购买，核对9/29可用及首次核销有效期，已购票不重复买。不要过早购买仅从购买日起计算短期有效的票；门票与演出预约是两件事。

    2026/2/13门票与演出预约指南，票种有效期以实际订单为准。

    预约流程参考。9/29固定放票时刻未确认，不套用其他日期的场次。

    建议9/29通过景区官方渠道确认已办好适用于9/30的门票；日期开放后也可提前购买，已购票不重复买。9/29晚查节目单，9/30入园后复核演出是否须预约。马战、水战建议提前45–60分钟到场。《大宋·东京梦华》是另外的演出票，本行程未默认购买。

09月25周五

北京 → 新乡｜会合 + 二胖

06:00出发，17:00–18:00抵达新乡；会合后逛二胖。

约650–670km含充电休息约11–12小时途中计划充电3次
  1. 06:00

    北京满电出发

    沿京港澳高速南下，按每约200km补能一次规划，途中预留3次充电。午饭、上厕所和休息尽量并入充电停留，电量不足就提前补能。

  2. 17:00–18:00

    预计抵达新乡

    先完成新乡东站会合，再前往二胖。接人、停车和市内转场另留30–60分钟；遇充电排队或堵车，后续安排顺延。

  3. 会合后

    胖东来生活广场（二胖）

    预计18:00–19:00左右到店，地址：新乡市卫滨区健康路31号。优先想买的服装、鞋靴，再按剩余营业时间逛超市和熟食。

  4. 逛完后

    晚饭 / 回酒店

    晚饭在二胖或周边就近解决，可穿插在购物间隙；逛完回银星酒店休息，并就近安排补电，为次日出发做准备。

银星酒店（中心医院胖东来店）
09月26周六

新乡 → 洛阳｜洛阳博物馆 + 西工小街 + 应天门

08:00出发；先保证洛博预约时段，入住顺路办理。晚上只安排西工小街晚饭和应天门南广场外拍。

约190km / 含补能预留3–3.5小时酒店→洛博约3km洛阳博物馆：免费
  1. 08:00

    新乡出发

    早餐后退房前往洛阳，提前补足电。这段接近200km，途中或到达后预留1次补能，按11:00–11:30左右抵达并安排午饭。

  2. 11:00–12:30

    就近午饭，入住不作为硬性步骤

    推荐牛肉汤配烧饼或饼丝。洛悦春梅酒店顺路且能办理入住，就先入住或寄存；需要等房或绕路时，先就近吃饭、按预约时段去洛博，出馆后再回酒店。补能尽量结合午饭完成，预留停车和入馆时间。

  3. 13:30–16:00

    洛阳博物馆

    拟按13:30入馆、参观约2–3小时规划，重点看河洛文明、唐三彩和珍宝类展陈；必须以成功预约的时段为准，不为赶后续项目匆忙离馆。

    门票：免费，须按馆方要求实名预约；本行程尚不代表预约成功。
    预约时间：9/24（周四）07:00。按查到的提前2天规则推算，建议06:55准备好同行人信息。9/23先核对中秋预约公告，如调整则按馆方新规则。渠道：“洛阳博物馆”官方微信公众号。查看完整预约表
  4. 17:30左右

    西工小街吃晚饭

    出馆后尚未入住就顺路办理，已入住则按体力短休，再去西工小街。吃小街锅贴，搭配浆面条、馄饨或粥；排队太久就换附近餐馆，不为吃饭反复绕行。

    吃完直接去应天门，不再折返酒店。两处不是同一个地点；步行或短途打车按体力选择，具体路线以当天地图为准，避免反复开车找停车位。
  5. 19:00–19:45

    应天门南广场｜只拍外观夜景

    西工小街吃完饭后直接前往，预留30–45分钟拍照打卡，不入内参观。明堂天堂外围仅作顺路备选，九洲池这晚不安排。

    预约：本次只在景区外拍照，不买应天门入内票或三景区联票；广场如有临时管制，按现场安排。
  6. 20:00后

    拍完回酒店，早点休息

    应天门拍照结束后回洛悦春梅酒店；明堂天堂外围仅在顺路、有体力时看一眼，不再加九洲池或洛邑古城。这晚不追最晚场，给次日龙门石窟留好体力。

洛悦春梅酒店（洛阳博物馆店）
09月27周日

洛阳｜龙门石窟 + 洛邑古城夜游

上午龙门，午饭后回酒店休息；17:30–20:30明确安排洛邑古城，不再作为二选一。

酒店→龙门约13km / 25–30分钟龙门石窟：90元 / 半价45元
  1. 07:00左右

    早餐后去龙门石窟

    停车优先导航“龙门石窟西北服务区停车场”。按酒店实际位置出发，争取07:30左右抵达停车区域，预留停车及步行到检票处的时间；不把到停车场当成已入园。

  2. 08:00–12:00

    龙门石窟

    尽量按08:00开始检票游览，实际以预约时段及假期开放公告为准。西北服务区 → 大石门 → 宾阳三洞 → 万佛洞 → 莲花洞 → 奉先寺 / 卢舍那大佛 → 漫水桥 → 礼佛台。以这条主线为重点，不为把通票用满而强行加走其他区域。

    门票：全价90元，半价45元；景交车单程10元。优惠资格按景区公示。
    建议9/20开始查看9/27门票，争取9/24前完成实名购票。这是提前7–3天的准备建议，不是已确认的放票窗口；若日期未开放，按官方系统提示办理。未核实统一放票时刻，不按网络攻略的固定几点抢票。查看渠道与依据
  3. 12:30–15:30

    午饭 + 回酒店午休

    返市区方向顺路吃饭，回酒店实际休息1–1.5小时；下午不再新增一个大景点，把体力留给洛邑古城。

  4. 16:30–17:15

    前往老城，就近吃晚饭

    优先在洛邑古城周边找合适的店吃饭，不为吃饭绕远。丽景门、十字街只作时间充裕时的顺路备选，不挤占古城游玩时间。

  5. 17:30–20:30

    洛邑古城｜明确安排，留足2–3小时

    傍晚入园，先慢逛，再看入夜后的文峰塔、新潭水畔与古街灯景。以散步、拍照为主，不以赶齐演出为目标；演出时间以当日节目单为准。

    建议9/24初查、9/26复核“洛邑古城”官方微信公众号的入园与预约要求。如需实名预约，选定9/27对应时段，开放后尽早办理；最早可预约几天、固定放票时刻及中秋票制尚未确认，不写成强制提前天数。
    票务：以9/27官方预约页面与活动公告为准，不把常态免费或往年收费活动直接套用到中秋。普通游览与另售演艺项目分开确认，不默认购买额外体验。
  6. 20:30后

    回酒店，休息与补电

    不再追加应天门或其他夜游点。按次日洛阳→开封行程提前安排补能，第二天早餐后退房。

洛悦春梅酒店（洛阳博物馆店）
09月28周一

洛阳 → 开封｜老城 + 夜市

08:00出发，中午到开封；入住后先午休，16:00左右再逛老城。晚上只选一处夜市，不增加大景区。

约193km / 含补能预留3.5–4小时酒店→鼓楼约6–7km开封老城街区：免费
  1. 08:00

    洛阳出发

    从洛悦春梅酒店退房后出发，前一晚补足电。途中或到达后预留1次补能，预计11:30–12:00左右到开封。

  2. 11:30–13:00

    午饭 + 入住丽呈睿轩酒店

    到达后就近吃午饭，入住或寄存行李；9/28入住，10/1退房，共3晚。

  3. 13:00–15:30

    入住后休息，不急着赶景点

    午饭后在酒店休息1–1.5小时，下午不再增加开封府等大景区。房间尚未准备好时就近找地方休息，按实际入住时间顺延。

  4. 16:00左右

    书店街、鼓楼轻松逛

    以街区散步为主，包公湖仅作顺路备选；不要求每个地点都走完。精力不足就减少下午步行，留好后两天逛园区的体力。

    门票：街区及包公湖周边散步不另设购票安排；收费景点不在本次必去清单。
  5. 18:00左右

    夜市晚饭，只选一个片区

    在鼓楼一带或西司夜市二选一吃晚饭，按酒店位置和当天所在片区决定，不来回赶两处。可吃炒凉粉、杏仁茶、锅贴、灌汤包等，吃完回酒店。

丽呈睿轩酒店（汴梁小宋城店）
09月29周二

开封｜万岁山重点演出 + 互动 + 夜场

先约三打祝家庄和打铁花，空档选感兴趣的街区互动、坐下休息，不以热门节目全部看完为目标。

酒店→万岁山约8–10km / 20–25分钟成人票100元 / 优待票50元
  1. 开园前20–30分

    到入口排队，准备入园

    前一晚在“万岁山武侠城”公众号查看节目单和地图。若当天08:00开园，就按07:40左右到入口，另外预留停车、步行时间。

    建议9/28（提前1天）购买适用于9/29的门票，核对首次核销有效期；已购票不要重复买。9/29正式场次尚未确认，入园后查看演出预约，开场与放票以当日为准；下列提前到场时间是建议，不保证有座。
  2. 入园立即

    先预约两场大秀

    四人检票入园后，打开“万岁山武侠城”公众号 → 侠客服务 → 演出预约，分别预约《三打祝家庄》、沙场《打铁花》，确认四人各有预约和座位号。

    预约时机：9/29当天完成入园检票后，不是提前几天约演出。入园即查两场预约入口，未放票按页面时间等候，满场就换场次；建议开演前30–40分钟到场，现场排队不能代替预约。预约流程参考
  3. 按预约场次

    三打祝家庄｜城寨沙场

    看《水浒传》题材的武打、攻防实景大戏。建议提前30–40分钟到预约页指定入口，凭预约对号入座；票面有更早要求则按票面执行。

  4. 两场之间

    街区互动 + 午休，王婆说媒可选

    街区可和江湖人物演员聊天、接任务、合影；午饭后留30–60分钟坐下休息。王婆说媒有兴趣且时间合适再看，按地图找舞台，建议提前20–30分钟到；不为每个热门演员反复排队。
