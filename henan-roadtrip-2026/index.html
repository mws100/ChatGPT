09月25周五

北京 → 新乡｜会合 + 二胖

北京出发，新乡东站会合，晚上逛二胖。

约650–670km含充电休息约11–12小时途中计划充电3次
  1. 06:00

    北京满电出发

    走京港澳高速，途中预留3次充电，结合午饭和休息。

  2. 17:00–18:00

    新乡东站会合

    接人后去二胖，接站和市内转场预留30–60分钟。

  3. 会合后

    逛胖东来生活广场（二胖）

    预计18:00–19:00到店。地址：卫滨区健康路31号；先逛服装鞋靴，再逛超市。

  4. 逛完后

    晚饭、回酒店

    在二胖或附近吃饭，回银星酒店休息，安排补电。

银星酒店（中心医院胖东来店）
09月26周六

新乡 → 洛阳｜洛阳博物馆 + 西工小街 + 应天门

下午逛洛博，西工小街吃晚饭，应天门拍夜景。

约190km / 含补能预留3–3.5小时酒店→洛博约3km洛阳博物馆：免费
  1. 08:00

    新乡出发

    早餐后退房，预计11:00–11:30到洛阳；途中或到达后补电。

  2. 11:00–12:30

    午饭、入住或寄存

    吃牛肉汤配烧饼或饼丝。酒店顺路就先入住，需等房则逛完洛博再办。

  3. 13:30–16:00

    洛阳博物馆

    参观河洛文明、唐三彩和珍宝展陈，入馆时间以预约为准。

    门票：免费，需实名预约。
    预约：按现有规则，9/24 07:00在“洛阳博物馆”官方公众号约票，建议06:55准备；假期调整以馆方公告为准。
  4. 17:30左右

    西工小街晚饭

    吃锅贴、浆面条或馄饨。饭后步行或打车去应天门，不折返酒店。

  5. 19:00–19:45

    应天门南广场拍夜景

    只拍外观，预留30–45分钟，不买入内票。明堂天堂外围顺路再看。

    广场如有临时管制，按现场安排。
  6. 20:00后

    回酒店休息

    回洛悦春梅酒店，早点休息。

洛悦春梅酒店（洛阳博物馆店）
09月27周日

洛阳｜龙门石窟 + 洛邑古城夜游

上午龙门石窟，午后休息，晚上逛洛邑古城。

酒店→龙门约13km / 25–30分钟龙门石窟：90元 / 半价45元
  1. 07:00左右

    出发去龙门石窟

    导航“龙门石窟西北服务区停车场”，争取07:30到达，留出步行入园时间。

  2. 08:00–12:00

    龙门石窟

    西北服务区 → 大石门 → 宾阳三洞 → 万佛洞 → 莲花洞 → 奉先寺大佛 → 漫水桥 → 礼佛台。

    门票：全价90元，半价45元；景交车单程10元，优惠资格以景区公示为准。
    购票：建议9/20起查看、9/24前办理9/27门票；未开放则按官方系统提示。入园时间以预约和开放公告为准。
  3. 12:30–15:30

    午饭、回酒店午休

    顺路吃午饭，回酒店休息1–1.5小时。

  4. 16:30–17:15

    老城晚饭

    在洛邑古城周边就近吃饭；丽景门、十字街有空再逛。

  5. 17:30–20:30

    洛邑古城夜游

    傍晚入园，逛文峰塔、新潭水畔和古街，散步拍夜景。

    入园：9/24查看、9/26复核官方公众号；9/27票价及预约要求待确认，以当天公告为准。
  6. 20:30后

    回酒店、补电

    回酒店休息，给车补电，准备次日去开封。

洛悦春梅酒店（洛阳博物馆店）
09月28周一

洛阳 → 开封｜老城 + 夜市

中午到开封，入住午休，傍晚逛老城、吃夜市。

约193km / 含补能预留3.5–4小时酒店→鼓楼约6–7km开封老城街区：免费
  1. 08:00

    洛阳出发

    早餐后退房，预计11:30–12:00到开封；途中或到达后补电。

  2. 11:30–13:00

    午饭、入住酒店

    就近吃午饭，入住丽呈睿轩酒店。9/28入住、10/1退房，共3晚。

  3. 13:00–15:30

    酒店午休

    休息1–1.5小时；未能入住则就近休息。

  4. 16:00左右

    书店街、鼓楼散步

    轻松逛街，包公湖顺路再去，不另加收费景点。

  5. 18:00左右

    夜市晚饭

    鼓楼或西司夜市选一处，吃炒凉粉、杏仁茶、锅贴、灌汤包，饭后回酒店。

丽呈睿轩酒店（汴梁小宋城店）
09月29周二

开封｜万岁山 + 夜场

看三打祝家庄和打铁花，穿插街区互动与休息。

酒店→万岁山约8–10km / 20–25分钟成人票100元 / 优待票50元
  1. 开园前20–30分

    到入口准备入园

    开园前20–30分钟到入口，另留停车、步行时间。

    建议9/28买好9/29门票并核对有效期；前一晚查看官方开园时间和节目单。
  2. 入园立即

    预约三打祝家庄、打铁花

    检票后打开“万岁山武侠城”公众号 → 侠客服务 → 演出预约，确认每人都有预约和座位。

    入园后才能约；未放票按页面时间再查，满场换场次。现场排队不能代替预约。
  3. 按预约场次

    三打祝家庄｜城寨沙场

    按预约看实景演出，建议提前30–40分钟到指定入口；票面要求优先。

  4. 两场之间

    街区互动、午休

    逛街、互动合影，午饭后休息30–60分钟。王婆说媒可选，想看则提前20–30分钟到。

  5. 傍晚 / 夜场

    晚饭、沙场打铁花

    17:00–18:00吃晚饭，再去城寨沙场。按预约提前30–40分钟到场，票面要求优先。

  6. 夜场后

    回酒店、补电

    夜场后直接回丽呈睿轩酒店，安排补电，继续住第二晚。

    门票：成人100元，优待50元；资格及规则以景区公示为准。
丽呈睿轩酒店（汴梁小宋城店）
09月30周三

开封｜清明上河园 + 夜景

上午马战、下午水战，晚上看夜景，仍住开封。

酒店→清园约7–9km / 20–25分钟成人票120元 / 优待票60元开封连住第3晚 · 10/1退房

    建议9/29买好门票并查节目单。下列场次仅供参考，9/30排期以当天为准。查看节目表
    门票：成人120元，优待60元，资格以景区公示为准；《大宋·东京梦华》另购票，本行程不含。
  2. 09:30–09:45

    岳飞枪挑小梁王｜马战

    到大宋·校场候场，参考10:30开演，建议提前45–60分钟。

  3. 11:30–13:00

    午饭、午休

    园内就近吃饭，休息45–60分钟，再往九龙桥走。

  4. 14:00–14:15

    大宋·东京保卫战｜水战

    到九龙桥西南观演区候场，参考15:00开演，建议提前45–60分钟。

  5. 16:00–17:30

    逛街、吃晚饭

    水战后慢逛宋代街区，吃晚饭、休息。

  6. 17:40–17:50

    可选：大宋·杨门女将

    按节目单去《东京梦华》主舞台，参考18:20开演，建议提前30–40分钟；累了就跳过。

  7. 19:00–20:30

    看夜景、回酒店

    看虹桥与河岸夜景，20:00–20:30左右离园，回丽呈睿轩酒店住第三晚。

    今晚补足电、整理行李，早点休息；明早返临沂。
