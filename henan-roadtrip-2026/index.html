9/25周五

北京 → 新乡新乡会合 + 胖东来大胖

第一天不再硬赶洛阳，在新乡汇合、逛胖东来并住一晚。

北京→新乡新乡东会合胖东来大胖住新乡
06:30

北京满电出发

沿京港澳高速南下。按元PLUS实际续航灵活安排服务区快充，不锁死充电站。

下午

新乡东站会合

济南过来的同行人直接乘高铁到新乡东，你开车到新乡后再会合，不需要在石家庄或邯郸下高速接人。

会合后

胖东来·大胖｜服装 + 超市

重点安排服装区和大众超市，建议预留3–4小时。先逛衣服，再逛超市和熟食，减少拎着食品逛街的时间。

这家作为本次胖东来主店使用，许昌胖东来行程已全部取消。
晚上

住新乡

酒店以停车方便、第二天出城顺路为优先，暂不锁定具体酒店。

9/26周六

新乡 → 洛阳龙门石窟 + 洛阳夜游

上午从新乡出发，中午到洛阳；下午集中玩龙门石窟，晚上看洛阳夜景。

牛肉汤龙门石窟应天门住汉庭
08:00

新乡出发去洛阳

睡够再走，不用太早。抵达后先去汉庭洛阳市政府宝龙广场店寄存行李或办理入住。

11:30

午饭｜洛阳牛肉汤

牛肉汤 + 烧饼/饼丝；不安排羊肉汤，也不吃洛阳水席。
13:00

龙门石窟

西北服务区停车 → 大石门 → 西山石窟 → 奉先寺 / 卢舍那大佛 → 漫水桥 → 礼佛台 → 返回

重点看西山核心石窟，不为了“全打卡”增加体力消耗。

18:00

晚饭｜西工小街一带

可安排小街锅贴 + 浆面条 / 馄饨 / 小米粥，吃完顺路夜游。
19:30

应天门 + 明堂天堂外围

以夜景和散步为主，还有体力再去洛邑古城；不要把晚上塞得太满，为第二天老君山留体力。

9/27周日

洛阳 ⇄ 老君山当天往返，不住栾川

两级索道都坐，玩十里画屏与金顶白天景观；下午提前下山，当晚回洛阳。

两级索道十里画屏金顶白天回洛阳住
06:15

洛阳满电出发

尽量在08:30前后到老君山，停车、检票后直接上山。

09:00

一级索道 + 二级索道

继续按“省体力”方案，两级索道都坐，把步行体力留给十里画屏。

09:30

核心路线

二级索道 → 十里画屏 → 马鬃岭 → 南天门 → 金顶道观群

白天完成主要景观即可，不再等待傍晚亮灯。

14:30

开始返程下山

14:30–15:00之间往索道返回，避免傍晚索道排队影响回洛阳。

目标：16:30前开车离开老君山停车场。
19:00

回到洛阳

回汉庭休息，当晚不再安排景点。原“栾川山合友酒店”和金顶亮灯行程全部删除。

9/28周一

洛阳 → 开封换城 + 开封轻松半日

睡够再出发，不赶大景区。下午博物馆或老城，晚上吃夜市。

洛阳→开封开封博物馆老城夜市开封连住3晚
09:00

洛阳出发

退房后直接开往开封，途中正常休息即可。

中午

入住 / 寄存行李

丽呈花千树酒店·开封鼓楼广场店作为当前候选，计划连住9/28、9/29、9/30三晚。

14:00

开封博物馆｜约上就去

如果预约不到，就改为书店街、鼓楼、包公湖周边慢逛，不影响后两天大景区。

18:00

开封老城 + 夜市

西司夜市或鼓楼一带，小份多样：炒凉粉、杏仁茶、锅贴、灌汤包等。羊汤和羊肉炕馍按你的口味直接跳过。
9/29周二

开封万岁山武侠城完整一天

不和清明上河园拼在同一天，把节目和夜场完整体验。

万岁山大型演出夜场
开园前

提前到景区

入园后第一件事看当天节目单和预约规则，先锁定最想看的大型演出。

全天

围绕大节目安排小节目

午饭、晚饭尽量都在园内解决，不出园折腾。热门节目和具体场次以当天官方节目单为准。

夜场后

回酒店休息

第二天还有清明上河园完整一天，晚上不再追加其他景点。

9/30周三

开封清明上河园完整一天

北宋市井、建筑和演出慢慢看，不和万岁山赶场。

清明上河园北宋市井演出夜景
上午

开园后入园

先看当天演出时间表，再按场次串联园区，不需要机械按地图从头走到尾。

白天

市井 + 建筑 + 演出

清明上河园与万岁山分开玩的目的，就是不用赶。累了就坐下来休息，优先体验最有代表性的节目。

晚上

夜景后回酒店

回酒店后把元PLUS充足电，为10月1日国庆返程做准备。

10/1周四

开封 → 临沂国庆返程

第一天假期重点是避堵和充电排队，不再安排必须玩到下午的景点。

早出发灵活补能
06:00

尽早离开开封

车尽量前一晚充满。早餐不为了名店绕路，优先早点上高速。

途中

根据空桩灵活补电

国庆服务区充电可能排队，不锁死某个站点；同时观察下一服务区距离和剩余电量。

当天

抵达临沂

如果出城顺利就直接赶路；如果高速已经明显拥堵，宁可在开封少停留，也不要中午再上高速。
