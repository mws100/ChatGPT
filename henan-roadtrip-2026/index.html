9/25
周五

北京 → 新乡｜新乡会合 + 二胖

第一天以长途驾驶和会合为主，下午到新乡后集中逛二胖。

🚗 约650–670km⏱ 含补能约9–10小时🎫 二胖：免费🏨 银星酒店
06:30

北京满电出发

沿京港澳高速南下。元PLUS按实际续航安排2–3次补能，午饭时可顺便多充一会。

15:30–16:30

预计抵达新乡

进入新乡后先完成会合，再去二胖。

17:00左右

胖东来生活广场（二胖）

地址：新乡市卫滨区健康路31号。先逛服装、鞋靴，再逛超市、生鲜和熟食，建议预留约3小时。

门票：免费。
20:00–21:00

晚饭 / 回酒店

在二胖或周边吃饭后，返回银星酒店休息。

9/26
周六

新乡 → 洛阳｜博物馆 + 西工小街 + 应天门

抵达洛阳后先入住或寄存行李，下午看洛博，晚上吃西工小街并看应天门夜景。

🚗 城际约190km / 2.5小时📍 酒店→洛博约3km / 10分钟🎫 洛阳博物馆：免费🏨 洛悦春梅酒店
08:00

新乡银星酒店出发

新乡到洛阳约190km，正常驾驶约2.5小时，途中按需要休息。

中午

牛肉汤 + 入住 / 寄存行李

推荐牛肉汤配烧饼或饼丝，之后前往洛悦春梅酒店（洛阳博物馆店）。

13:30

洛阳博物馆｜预留约2.5小时

重点看河洛文明、唐三彩和珍宝类展陈。提前在官方渠道实名预约并带好证件。

门票：免费，实名预约入馆。
16:00

回酒店短休

下午短休后再进西工片区。

17:30

西工小街晚饭

推荐小街锅贴，搭配浆面条、馄饨或粥。

酒店 → 西工小街约9km / 20–25分钟
西工小街 → 应天门约3km / 10–15分钟
应天门 → 酒店约8km / 20分钟
19:00

应天门 + 明堂天堂外围

以北广场、建筑夜景和散步拍照为主。

门票：外围夜景免费；如入内，以当天官方票价为准。
21:00

回洛悦春梅酒店休息

9/26入住，连住两晚。

9/27
周日

洛阳｜龙门石窟 + 午休 + 老城慢逛

上午把体力留给龙门石窟，下午休息，傍晚逛丽景门—十字街或洛邑古城。

📍 酒店→龙门约13km / 25–30分钟🎫 龙门石窟：90元 / 半价45元🚌 景交车10元/次（可选）🏨 洛悦春梅酒店
07:00

早餐后去龙门石窟

从洛悦春梅酒店出发，按08:00–08:30到景区停车场规划。

08:30

龙门石窟｜白天精华

停车优先导航“龙门石窟西北服务区停车场”。路线：西北服务区 → 大石门 → 宾阳三洞 → 万佛洞 → 莲花洞 → 奉先寺 / 卢舍那大佛 → 漫水桥 → 礼佛台。

门票：全价90元，半价45元；景交车单程10元。
12:30

午饭 + 午休

返市区方向顺路吃午饭，时间合适就回酒店午休。

15:30

老城慢逛｜丽景门—十字街

丽景门外观 → 东西大街 → 十字街晚饭；若更想拍照，可把17:00–19:00换成洛邑古城。

门票：丽景门外观、老城街区、洛邑古城常规游览按免费项目安排；内部展馆或体验另计。
19:00

结束游览

有晚间火车安排时，结束后直接取行李前往票面车站；否则返回洛悦春梅酒店休息。

9/28
周一

洛阳 → 开封｜入住 + 老城 + 夜市

上午换城，下午以老城轻松游为主，晚上吃夜市。

🚗 约193km / 2小时45分📍 酒店→鼓楼约6–7km / 20分钟🎫 开封老城街区：免费🏨 丽呈睿轩酒店
09:00

洛阳出发

从洛悦春梅酒店退房后直接开往开封。

中午

入住丽呈睿轩酒店

入住开封宋城路站丽呈睿轩酒店（汴梁小宋城店），住9/28、9/29两晚。

14:00

开封老城｜书店街、鼓楼或包公湖周边

周一以老城街区为主，慢慢逛。

门票：书店街、鼓楼周边街区、包公湖周边散步免费；进入收费景点另购票。
18:00

夜市

推荐西司夜市或鼓楼一带，尝试炒凉粉、杏仁茶、锅贴、灌汤包等。

9/29
周二

开封｜万岁山完整一天 + 夜场

这一天只玩万岁山，围绕大节目安排路线，不和其他大景区赶场。

📍 酒店→万岁山约8–10km / 20–25分钟🎫 成人票100元 / 优待票50元🎭 主要演出含在门票内🏨 丽呈睿轩酒店
开园前

从酒店出发

尽量开园前后到景区，入园先看当天节目单与预约规则。

全天

围绕大型演出安排路线

午饭、晚饭尽量园内解决，把时间留给主要节目和夜场。

门票：成人票100元，优待票50元；票种和使用规则以景区当天公告为准。
夜场后

回酒店休息

夜场结束后返回丽呈睿轩酒店，这是开封第二晚。

9/30
周三

开封｜清明上河园完整一天 → 夜间返临沂

白天和晚上都留给清明上河园，夜景结束后直接开始返程。

📍 酒店→清园约7–9km / 20–25分钟🎫 成人票120元 / 优待票60元🚗 开封→临沂约443km / 约6小时🏨 9/30退房
上午

退房 + 前往清明上河园

早餐后办理退房。行李可装车或寄存前台；若寄存，夜间返程前先回酒店取行李。

白天

清明上河园｜市井 + 建筑 + 演出

先看当天演出时间表，再按场次串联园区，中间留出吃饭和休息时间。

门票：成人票120元，优待票60元；《大宋·东京梦华》另购。
夜景后

开始返临沂

清明上河园夜景结束后开始返程，预计约20:30–21:00出发，具体按当天演出和离园时间调整。

夜间约443km，建议轮换驾驶并每2小时休息；出现疲劳就进服务区休息，不硬赶。
10/1
周四

临沂｜凌晨 / 清晨抵达

9月30日晚从开封出发，预计10月1日凌晨或清晨抵达临沂。

🚗 夜间返程约443km⚡ 途中按电量补能🎫 无门票
凌晨

抵达临沂

到达后以休息为主，河南段行程结束。
