09月25周五

北京 → 石家庄｜正定古城 + 隆兴寺

05:00早走，上午先到正定；正定就在进石家庄前面，顺路玩，不来回折返。

北京→石家庄约292km含补能约4.5–5.5小时石家庄第1晚
  1. 05:00

    北京满电出发

    走京港澳方向，早饭和补能合并安排；这一天路程比原来直奔新乡轻松很多。

  2. 09:30–10:30

    到正定、停车

    根据当天路况决定先吃点东西还是直接开始逛。行李留车上，贵重物品随身。

  3. 上午–下午

    隆兴寺 + 正定古城

    先把隆兴寺作为核心，再顺着古城街区慢慢逛；不用刷很多小景点，重点是走得舒服。

  4. 17:00左右

    进石家庄市区、入住

    正定到石家庄市区距离不远，入住后先休息、补电。

  5. 晚间

    晚饭、早点休息

    不再安排夜场，给第二天河北博物院留体力。

石家庄市区酒店（待定）· 第1晚
09月26周六

石家庄｜河北博物院 + 轻松休息

今天不赶城际，核心只放河北博物院，下午留出休息时间。

河北博物院：免费预约建议预约上午石家庄第2晚
  1. 08:30左右

    早餐后去河北博物院

    提前按官方规则预约；尽量选上午时段，进馆后不用赶展厅。

  2. 09:00–13:00

    河北博物院

    重点看满城汉墓、中山国、名窑名瓷等代表展览，中途坐下来休息一次。

  3. 13:00–15:30

    午饭 + 回酒店休息

    下午不再安排第二个大景点，避免连续两天走太多。

  4. 17:00后

    市区轻松逛、晚饭

    看体力决定是否出门；不想逛就直接休息。

  5. 睡前

    补电、整理行李

    明早去开封，尽量把车补到高电量。

石家庄市区酒店（同住）· 第2晚
09月27周日

石家庄 → 开封｜转场 + 休息

今天把四百多公里长途单独拿出来，不安排开封收费景点。

约438km含补能约6–7小时开封第1晚
  1. 08:00左右

    石家庄退房出发

    走高速去开封，途中把充电、午饭和休息尽量合并。

  2. 途中

    补能 + 午饭

    按元PLUS实际电量安排1–2次补能，不把续航压得太低。

  3. 14:00–15:30

    抵达开封、入住

    具体时间按高速路况和充电排队调整，到了先休息。

  4. 傍晚

    附近吃饭、散步

    不去开封博物馆，也不新增收费景点；早点休息，明天正式玩万岁山。

丽呈睿轩酒店（汴梁小宋城店）· 第1晚
09月28周一

开封｜万岁山武侠城 + 夜场

开封第一整天只玩万岁山，把时间留给重点演出和夜场。

成人100元 / 优待50元全天开封第2晚
  1. 08:30左右

    早餐后去万岁山

    停车入园后第一件事先看当天节目单和预约规则。

  2. 入园立即

    先处理热门演出

    重点盯《三打祝家庄》和打铁花，按当天小程序或现场规则预约。

  3. 上午

    武侠街区 + 实景演出

    围绕已约场次逛核心街区，看巡游和互动，不为了小节目来回折返。

  4. 12:00–14:00

    午饭 + 休息

    园内解决午饭，至少坐下来休息40–60分钟。

  5. 下午–夜场

    重点演出 + 打铁花

    按当天节目单安排，夜场结束后直接回酒店。

    门票：具体票价、优惠资格和节假日规则以景区当天公示为准。
丽呈睿轩酒店（汴梁小宋城店）· 第2晚
09月29周二

开封｜清明上河园 + 夜景

开封第二整天只玩清明上河园，白天演出，晚上看园区亮灯。

成人120元 / 优待60元全天开封第3晚
  1. 08:15左右

    早餐后去清明上河园

    入园后先看最新节目单，再围绕马战、水战安排全天路线。

  2. 上午

    核心街区 + 马战

    先逛虹桥、上善门周边，再按节目单去大宋·校场看重点演出。

  3. 11:30–13:00

    午饭、午休

    园内就近吃饭，找有座位的地方休息45–60分钟。

  4. 下午

    水战 + 宋代街区

    按节目单看水战，之后慢慢逛店铺、作坊和河岸。

  5. 19:00–20:30

    虹桥与河岸夜景

    看完夜景回酒店，补电、整理行李；第二天直接返临沂。

    门票：《大宋·东京梦华》另购票，本行程默认不安排。
丽呈睿轩酒店（汴梁小宋城店）· 第3晚 · 9/30退房

  3. 下午 / 傍晚

    抵达临沂

    到家后休息，不再安排景点。
