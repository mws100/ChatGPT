9/25
周五

北京 → 新乡｜新乡会合 + 二胖

北京到新乡约650–670km；纯驾驶约7–8小时，含充电、吃饭和休息按9–10小时准备。

06:30

北京满电出发

沿京港澳高速南下。元PLUS 430km版本按实际续航安排2–3次补能，服务区是否排队以当天为准。

途中

充电 + 午饭

根据剩余电量和空桩情况灵活补能，午饭时可以顺便多充一会。

15:30–16:30

预计抵达新乡

按正常路况和2–3次补能估算，06:30出发大约这个时间段进入新乡；节前堵车时适当顺延。

下午

新乡东站会合

济南出发的同行人直接乘高铁到新乡东站，你到站后会合。

17:00左右

胖东来生活广场（二胖）

地址：新乡市卫滨区健康路31号。重点逛服装、鞋靴和超市，建议预留约3小时。

顺序建议：先逛服装 → 再逛超市、生鲜和熟食。
20:00–21:00

晚饭 / 回酒店

可以在二胖解决一部分吃饭和采购，再回银星酒店（中心医院胖东来店）休息。

9/26
周六

新乡 → 洛阳｜博物馆 + 应天门夜景

上午从新乡前往洛阳，下午参观洛阳博物馆，晚上西工小街吃饭后看应天门夜景。

08:00

新乡银星酒店出发

早餐后退房前往洛阳，按11:00–12:00抵达预留时间；实际到达以导航、休息和交通情况为准。

中午

牛肉汤 + 入住 / 寄存行李

推荐牛肉汤配烧饼或饼丝。酒店顺路就寄存行李；否则参观后再办理入住，减少折返。

13:30

洛阳博物馆｜约上才去，预留约2.5小时

建议13:30–16:00参观，重点看河洛文明、唐三彩和珍宝类展陈。提前从洛阳博物馆官方微信公众号预约，四人均按对应身份要求预约并带证件原件。

官网常规开放时间为09:00–19:00，18:30停止入馆。当天实际安排以馆方公告和预约页面为准。若9/26没约到但9/27下午有票，可将博物馆调整到次日下午。
16:00

入住 + 短休

预留至17:30用于交通、办理入住和休息，然后前往西工片区吃晚饭。

17:30

西工小街晚饭

推荐小街锅贴，搭配浆面条、馄饨或粥。饭后直接前往应天门。
19:00

应天门 + 明堂天堂外围

建议19:00–20:30看建筑夜景、散步拍照。灯光秀与演出以当天官方安排为准。

21:00

回洛阳住处休息

9/26入住、9/28退房，连住两晚。按两间双床房、每人一张独立床和一床被子筛选，洛阳酒店待确认。

9/27
周日

洛阳｜龙门石窟 + 老城慢逛

上午集中游览龙门石窟，午后休息，傍晚安排丽景门—十字街或洛邑古城。

07:00

早餐后去龙门石窟

在住处附近吃早餐，按08:00–08:30到景区停车场规划出发；具体时间等酒店确定后按导航调整。

08:30

龙门石窟｜白天精华，预留3–4小时

停车导航优先设“龙门石窟西北服务区停车场”；遇分流则服从现场指引。官网显示08:00开始售票/入园，西北服务区到石窟检票处步行约20分钟，可乘景交车。

建议路线：西北服务区 → 大石门 / 西山入口 → 宾阳三洞 → 万佛洞 → 莲花洞 → 奉先寺 / 卢舍那大佛 → 西山南端 → 漫水桥 → 礼佛台。重点游览西山精华，东山、香山寺和白园根据体力与时间决定。
12:30

午饭 + 午休

龙门游览结束后往市区方向走，顺路吃午饭，留出约1小时坐下来休息；酒店顺路就回房午休。

15:30

老城二选一｜丽景门—十字街

主线：丽景门外观 → 东西大街慢逛 → 十字街晚饭，建议15:30–19:00完成。若更想拍照看夜景，可将17:00–19:00安排为洛邑古城。

推荐牛肉类、锅贴、面食等，四个人可以分着点几样。老城一片停一次车，再步行或打车衔接。
19:00

结束游览｜预留晚间交通时间

如当晚有22:00火车安排，19:00结束游览后取行李前往票面车站，建议20:30前到站；注意区分洛阳站与洛阳龙门站。没有乘车安排则返回住处休息。

9/28
周一

洛阳 → 开封｜轻松半日

早餐后出发，下午以老城休闲为主，晚上夜市。

09:00

洛阳出发

从洛阳住处退房后直接开往开封。

中午

酒店寄存行李 / 入住

开封酒店尚未最终确定，计划9/28、9/29、9/30连住三晚。

14:00

开封老城｜书店街、鼓楼或包公湖周边

9/28是周一，开封博物馆按常规周一闭馆。若馆方明确临时开放且预约成功，可将博物馆作为替代安排；否则按老城与夜市主线走。

18:00

老城 + 夜市

推荐西司夜市或鼓楼一带，尝试炒凉粉、杏仁茶、锅贴、灌汤包等。

9/29
周二

开封｜万岁山完整一天

一整天留给万岁山，把主要节目和夜场完整体验。

开园前

提前到景区

入园第一件事看当天节目单和预约规则。

全天

围绕大型演出安排路线

午饭晚饭尽量园内解决，按主要演出时间串联路线。

夜场后

回酒店休息

夜场结束后返回酒店，为第二天清明上河园留足体力。

9/30
周三

开封｜清明上河园完整一天

北宋市井、建筑、演出和夜景慢慢看。

上午

开园后入园

先看当天演出时间表，再按场次串联园区。

白天

市井 + 建筑 + 演出

根据演出时间安排游览节奏，中间留出吃饭和休息时间。

晚上

夜景后回酒店

回酒店后把元PLUS充足电，为10月1日返程准备。

10/1
周四

开封 → 临沂｜国庆返程

重点避堵和充电排队。

06:00

尽早离开开封

前一晚尽量充满电，早餐就近解决后出发。

途中

灵活补电

根据空桩和剩余续航调整，不锁死服务区。
