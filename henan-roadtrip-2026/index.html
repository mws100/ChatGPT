09月25周五

北京 → 新乡｜会合 + 胖东来

把出发时间提前到05:00，尽量避开后面的雨和车流。

约650–670km含充电休息约11–12小时途中计划充电3次
  1. 05:00

    北京满电出发

    走京港澳高速，第一段尽量多跑一会儿；充电结合早餐、午饭和休息完成。

  2. 16:00–17:30

    抵达新乡、新乡东站会合

    实际到达按当天路况调整；如果提前到，就先去酒店办理入住或补电。

  3. 会合后

    胖东来生活广场（二胖）

    地址：卫滨区健康路31号。先逛服装鞋靴，再逛超市，不另绕路找景点。

  4. 晚间

    晚饭、回酒店

    在二胖或附近解决晚饭，回酒店休息并把电补好，第二天去开封。

银星酒店（中心医院胖东来店）
09月26周六

新乡 → 开封｜万岁山武侠城 + 夜场

开封第一天只玩万岁山，不再安排开封博物馆或其他收费景点。

新乡→开封约109km成人100元 / 优待50元开封第1晚
  1. 07:00

    新乡退房出发

    早餐后尽早走，约1.5–2小时到开封。行李先放酒店或直接随车，尽量不耽误万岁山白天场次。

  2. 09:00左右

    到万岁山、入园

    停车后直接入园，第一件事先看当天节目单和预约规则。

  3. 入园立即

    优先处理热门演出

    先盯《三打祝家庄》和打铁花，按当天小程序或现场规则预约；预约成功后再围绕场次安排街区项目。

  4. 上午

    武侠街区 + 实景演出

    先逛核心街区，看快闪、巡游和互动，不要为了小项目来回折返。

  5. 12:00–14:00

    午饭 + 休息

    园内解决午饭，坐下来休息40–60分钟，为下午和夜场留体力。

  6. 下午

    三打祝家庄等重点演出

    按预约场次提前候场；王婆说媒等项目有空再看，不强求全刷。

  7. 傍晚 / 夜场

    晚饭 + 打铁花

    看完夜场后直接回酒店休息，不再加夜市。

    门票：全价100元、优待50元；具体优惠资格和节假日规则以景区当天公示为准。
丽呈睿轩酒店（汴梁小宋城店）· 第1晚
09月27周日

开封｜清明上河园 + 夜景

开封第二天只玩清明上河园，白天看演出，晚上看亮灯后的园区。

酒店→清园约7–9km成人120元 / 优待60元开封第2晚
  1. 08:15左右

    早餐后去清明上河园

    今天不退房，尽量在开园后不久入园，先看最新节目单，再定全天线路。

    门票：全价120元、优待60元；《大宋·东京梦华》另购票，本行程默认不看。
  2. 上午

    核心街区 + 岳飞枪挑小梁王

    先逛虹桥、上善门周边，再按当天节目单去大宋·校场看马战，热门场次提前候场。

  3. 11:30–13:00

    午饭、午休

    园内就近吃饭，找有座位的地方休息45–60分钟。

  4. 下午

    东京保卫战 + 宋代街区

    按节目单看水战，之后慢慢逛店铺、作坊和河岸，不再赶太多小演出。

  5. 17:00–18:00

    晚饭、休息

    提前把饭吃好，等天黑后看园区亮灯。

  6. 19:00–20:30

    虹桥与河岸夜景

    看完夜景回酒店，把电补足、整理行李；明早退房去郑州。

丽呈睿轩酒店（汴梁小宋城店）· 第2晚 · 9/28退房
09月28周一

开封 → 郑州｜只有河南·戏剧幻城

开封退房后直接去中牟，玩完再进郑州市区。

开封→景区约40分钟左右以剧场体验为主郑州第1晚
  1. 08:30

    开封退房出发

    行李直接放车上，导航“只有河南·戏剧幻城”，不先进郑州市区。

  2. 09:30左右

    停车、取票、确认主剧场次

    先确认今天所含主剧和场次，再安排小剧场；至少提前到所选主剧开演前30分钟入园。

  3. 10:00–13:00

    第一轮剧场

    优先看已选主剧，再穿插小剧场；具体以当天节目单为准。

  4. 13:00–14:00

    园内午饭 + 休息

    中午至少休息40分钟，不连续站着看剧。

  5. 14:00–19:30

    第二轮剧场 + 幻城空间

    继续看主剧、小剧场和建筑空间，不追求一天刷完，优先把最想看的大戏看完整。

  6. 20:00后

    去郑州市区酒店

    离园后再开车进郑州，入住后直接休息。

郑州市区酒店（待定）· 第1晚
09月29周二

郑州｜河南博物院 + 二七广场

这天以室内文化行程为主，下午和晚上安排轻松一点。

河南博物院：免费预约重点半天郑州第2晚
  1. 09:00–09:30

    到河南博物院

    按预约时段入馆，先看“泱泱华夏 择中建都”，再按体力补国宝、青铜器和临展。

  2. 09:30–13:30

    河南博物院深度参观

    重点看代表性文物，中途安排一次坐下休息，不赶展厅。

  3. 13:30–15:30

    午饭 + 酒店休息

    吃完回酒店休息，下午不再塞博物馆。

  4. 17:00左右

    二七广场、德化街

    傍晚出来走走，看看二七纪念塔和老商业街，逛1–2小时即可。

  5. 19:00后

    晚饭、回酒店

    就近吃饭，早点回去休息。

郑州市区酒店（待定）· 第2晚
09月30周三

郑州｜机动休息日

不再硬塞大景点，给前面连续几天高强度游玩留一个缓冲。

睡到自然醒按天气决定郑州第3晚
  1. 上午

    睡到自然醒

    连续玩万岁山、清明上河园和只有河南以后，这天上午不定闹钟也可以。

  2. 中午

    找一家顺路的本地饭馆

    不为了吃饭跨城绕路，优先酒店附近解决。

  3. 下午

    按天气和体力临时决定

    天气好就市区散步或找一个轻量景点；下雨就商场、咖啡馆、休息，不强行安排户外。

  4. 傍晚

    提前吃晚饭

    晚上不安排远距离活动，给第二天长途返程留足睡眠。

  5. 20:00前后

    补足电、收行李

    把车补满或补到足够出城，检查证件、充电卡和随车物品。

郑州市区酒店（待定）· 第3晚 · 10/1退房
10月01周四

郑州 → 临沂｜返程

国庆首日尽量早走，全天只做返程，不再加景点。

约506km含补能按8–10小时预留途中计划充电2次
  1. 06:30–07:00

    早餐、退房返程

    检查行李、证件、胎压和电量，尽量在国庆车流完全起来前出郑州。

  2. 返程途中

    2次补能 + 午饭

    约506km，按元PLUS的节假日高速节奏留2次充电；哪一站不拥堵就在哪一站多补一点。

    平时纯驾驶约5.5小时，但10月1日不要按平日时间算；充电排队和堵车都另留机动。
  3. 下午 / 傍晚

    抵达临沂

    到达后休息，当天不再安排游览。
