9/25周五

北京 → 洛阳只赶路，不安排景点

最累的一天，把体力全部留给驾驶和补能。

≈798km约4次快充住汉庭
06:00

北京满电出发

按150–180km一个补能观察点规划，单次20%–30%充到75%–85%更省时间。

全天

高速 + 快充

预计4次左右快充；午饭那次可以多充一点。遇到服务区排队就灵活换下一处。

19:30+

抵达洛阳

入住 汉庭酒店（洛阳市政府宝龙广场店）。当天不再追美食店，附近吃热饭、洗澡、休息。

9/26周六

洛阳龙门石窟 + 博物馆 + 应天门

洛阳核心日：早上石窟，下午博物馆可选，晚上看城楼夜景。

牛肉汤龙门石窟博物馆可选小街锅贴
06:40

早餐｜洛阳牛肉汤

推荐：兄弟俩老李家牛肉汤（洛龙店）
牛肉汤 + 饼丝/烧饼，可加一份牛肉。羊肉汤取消。
07:30

开车去龙门石窟

导航直接设：“龙门石窟西北服务区停车场”。假期如交警分流到东北服务区，服从现场分流，不逆行找西北。
08:00

龙门石窟｜从大石门 / 西山入口进

西北服务区停车 → 大石门 → 潜溪寺 → 宾阳三洞 → 摩崖三佛龛 → 万佛洞 → 莲花洞 → 奉先寺 / 卢舍那 → 古阳洞（体力允许）→ 西山南门 → 漫水桥 → 礼佛台

不专门爬东山。礼佛台拍完整西山全景后，询问工作人员当天返回西北服务区的电瓶车站点。景区以单向游览为主，奉先寺等重要内容要在出西山前拍完。

教师资格证 + 本人身份证：按现行政策可按45元半价票预算。
11:45

午饭 + 回酒店短休

午饭简单解决，12:30左右回汉庭休息一会儿。

14:20

洛阳博物馆｜预约成功才去

如果能约到9/26，就安排约1.5–2小时。重点看河洛文明、唐三彩、珍宝类代表性文物，不追求每个展厅全看。

约不上：直接把下午恢复成酒店午休，16:30左右再出门，不影响晚上。
17:20

晚饭｜西工小街锅贴

推荐：西工小街锅贴
锅贴 + 浆面条 / 馄饨 / 小米粥。允许稍微绕路，因为本身值得吃。
19:00

应天门夜景

应天门北广场 → 明堂天堂外围。还有体力再去洛邑古城 / 丽景门二选一。

9/27周日

洛阳 → 老君山 → 栾川完整山景日

两级索道换体力，把精力留给十里画屏和金顶亮灯。

两级索道十里画屏金顶夜景住山合友
07:00

洛阳满电出发

约150–170km，90%–100%电量出发，中途通常不用补电。

09:00

抵达老君山

停车、检票、准备冲锋衣/抓绒等保暖层。

09:30

两级索道 + 核心路线

一级索道 → 二级索道 → 十里画屏 → 马鬃岭 → 南天门 → 金顶道观群

一级索道往返约130元；二级往返约80元。你不想太累，建议都坐。

教师资格证 + 身份证：老君山门票按50元半价预算；索道无教师优惠。
15:30

山顶休息，等日落和亮灯

吃热食、补水、找地方坐着。9/26晚再次确认9/27当天亮灯及索道运营时间。

亮灯后

尽快下山 → 栾川山合友酒店

住 栾川山合友酒店（老君山凤凰天街店），滨河北路1号。酒店停车、充电方便。

晚饭首选：大有自在小馆
推荐栾川豆腐、橡子面饺、凉拌笋片；下山太晚就改凤凰天街其他本地菜。
9/28周一

栾川 → 许昌胖东来购物日

大众服饰看鞋和衣服，时代广场体验百货与自营食品。

≈295km1次快充大众服饰时代广场住三国大酒店
08:00

山合友酒店出发

约295km，中途安排1次快充 + 简餐。

13:00

入住三国大酒店

三国大酒店（胖东来时代广场曹魏古城店），七一路636号；停车、充电方便。

14:00

胖东来大众服饰

重点看鞋、男装、女装、服饰类商品，预留约3小时。

17:10

胖东来时代广场

继续逛百货、超市、熟食、烘焙和自营商品。

美食体验：熟食、烘焙、牛肉类零食、甜品可以顺便买，不额外再跑一顿大餐。
9/29周二

许昌 → 开封老城慢逛 + 美食

开封府删除。把时间还给老街、湖边和吃东西，节奏更舒服。

胡辣汤邢家锅贴鼓楼/书店街龙亭湖周边西司夜市
07:00

许昌早餐｜胡辣汤 + 水煎包

推荐：丁小旭胡辣汤
肉胡辣汤 + 水煎包 / 葱油饼。为了当地早餐允许小绕路。
08:30

许昌出发去开封

约129km，预计10:30左右到开封。先去酒店停车/寄存行李。

11:30

开封午饭｜邢家锅贴老店

建议：鲜肉韭黄锅贴 + 炒凉粉 + 桶子鸡。两个人不必点大份鲤鱼焙面。
13:00

书店街 + 鼓楼周边

慢慢走、拍照、逛小店，不安排收费景点，不追演出。

15:30

龙亭湖周边散步

以湖边、古城氛围、街景为主，不强制买龙亭景区门票。累了就找咖啡店/茶馆坐一会。

18:30

西司广场夜市

小份多样：炒凉粉、杏仁茶、涮牛肚、灌汤包、四味菜。你不喜欢羊膻味，羊肉炕馍和羊汤直接跳过。
9/30周三

开封万岁山武侠城完整一天

只做一个大景点，把节目和夜场体验完整。

三打祝家庄打铁花夜场
07:45

到景区

入园第一件事看当天节目单和预约规则，热门节目以小程序当天为准。

全天

围绕大型演出安排小节目

重点《三打祝家庄》《打铁花》，午饭晚饭都在园内解决，不出园折腾。

21:30+

离园 → 回酒店充满电

第二天国庆返程，把车充到100%。

10/1周四

开封 → 临沂国庆返程

高速免费，但重点防堵车和服务区充电排队。

≈440km约2次快充
06:00

满电出发

不为了早餐绕路，尽早离开开封。

途中

按实时空桩补电

准备约2次快充，不锁死具体服务区，根据剩余续航、空桩和排队情况灵活调整。
