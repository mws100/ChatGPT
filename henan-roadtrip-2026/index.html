河南自驾最终详细行程

住宿已确定：洛阳2晚住汉庭酒店（洛阳市政府宝龙广场店）；9/27住栾川山合友酒店（老君山凤凰天街店）；许昌住三国大酒店（胖东来时代广场曹魏古城店）。
饮食调整：不安排洛阳水席。吃饭优先选景点/酒店顺路的小店，不为了网红店专门跨城绕路。
已删除景点：白马寺、九洲池、大相国寺、天界山、宝泉。

9月25日｜北京 → 洛阳

06:00左右北京满电出发，约798km。当天不安排景点，按150–180km一个补能观察点规划，预计4次左右快充。

到洛阳后：直接入住汉庭酒店（洛阳市政府宝龙广场店）。当天吃饭就在宝龙广场/酒店周边解决，长途驾驶后不要再专门跑老城区找吃的。

9月26日｜龙门石窟 + 洛阳夜景

06:50–07:30｜早餐：龙门李家三旦羊肉汤馆

导航：“龙门李家三旦羊肉汤馆”，龙门大道863号龙门地热宾馆内。营业时间约05:30–11:30，人均约20多元。羊肉汤 + 馍/饼丝即可。吃完直接继续往龙门石窟，路线顺。

07:40左右｜自驾去龙门石窟，停车位置写死

导航目的地优先设：“龙门石窟西北服务区停车场”或“龙门石窟西北服务区”。
为什么停这里：官方西北服务区约2000个车位，至检票口步行官方参考约20分钟；东北服务区约5000个车位，但步行约25分钟。你们想省体力，优先西北。
节假日例外：如果现场交警把车流分到东北服务区，不要逆行找西北，按分流停车，再坐电瓶车。

08:00–11:30｜从哪个门进、里面怎么走

停车后：跟指示牌往“大石门 / 西山石窟入口”走。西北服务区到检票口不想走可坐电瓶车，单程10元/人。

省体力精华线：西北服务区停车场 → 大石门检票 → 西山石窟北端 → 潜溪寺 → 宾阳三洞 → 摩崖三佛龛 → 万佛洞 → 莲花洞 → 奉先寺 / 卢舍那大佛 → 古阳洞、药方洞（体力允许再看） → 西山南门 → 漫水桥 → 东岸礼佛台拍西山全景。

到礼佛台后不要硬爬东山。你们这趟重点是西山和卢舍那大佛。礼佛台拍完后，直接询问现场工作人员当天返西北服务区的电瓶车站点；景区电瓶车线路会根据客流调整。若当日不能直接返回，就继续按工作人员指引到白园停车场/龙门桥一侧再换返程车。

非常重要：景区实行单向游览，西山石窟走出闸口后不要想着原路返回，所以奉先寺、卢舍那等想拍的内容要在出西山前拍完。

门票：全价90元；持教师资格证 + 本人身份证的外地人民教师按当前官方政策可购半价票45元。9/26属于假期客流期，提前实名购票。

11:45–14:30｜午饭 + 回酒店休息

不吃水席。从龙门回来后直接回洛龙区，宝龙广场周边吃烩面、牛肉汤、锅贴这类简单午饭，然后回汉庭休息。不要把午休挤掉。

18:00以后｜晚饭 + 应天门

如果晚上还想去洛邑古城，可把南关小碗牛肉汤（南关老店）作为备选，它在洛邑古城西侧不远，吃完再逛古城比较顺；如果不去洛邑古城，就直接在酒店/应天门途中解决。

19:20左右看应天门北广场、明堂天堂外围夜景；体力够再去洛邑古城或丽景门二选一。

9月27日｜洛阳 → 老君山 → 栾川

07:00从洛阳满电出发，约150–170km，预计09:00左右到老君山。

索道方案

  • 老君山门票：100元；教师资格证 + 身份证半价50元
  • 一级索道往返：130元，建议必坐
  • 二级索道往返：80元，想省体力建议坐
一级索道 → 二级索道 → 十里画屏 → 马鬃岭 → 南天门 → 金顶道观群 → 等亮灯 → 两级索道下山

9/26晚再次核对9/27当天亮灯时间和索道运营公告。

下山后住宿：栾川山合友酒店

酒店全名：栾川山合友酒店（老君山凤凰天街店），地址栾川滨河北路1号。距老君山景区约7.8km，正常自驾约十几分钟；有免费停车场和充电车位。下山后直接开去酒店，不住七里坪。

晚饭

酒店距凤凰天街约780m。体力还行就去伊家厨庄（滨河大道凤凰天街B栋对面），人均约46元，可点栾川豆腐、砂煲羊排一类；想环境好一点可选大有自在小馆（凤凰天街C栋2楼）。如果下山太晚，直接酒店餐厅/附近吃，不强行跑店。

晚上尽量把车补到90%–100%。

9月28日｜栾川 → 许昌胖东来

07:30酒店早餐，08:00左右从山合友酒店出发。栾川到许昌约295km，中途安排1次快充 + 简餐。

13:00左右到许昌，入住三国大酒店（胖东来时代广场曹魏古城店），七一路636号；免费停车、有充电位，距时代广场约370m。

14:00–17:00｜胖东来大众服饰

地址：颍昌路838号。重点看鞋、男装/女装和服饰。

17:10–20:30｜胖东来时代广场

地址：七一路277号。继续逛百货、超市、熟食/烘焙。晚饭直接在时代广场餐饮/熟食区解决最顺路；如果逛累了，也可直接回三国大酒店八层餐厅吃，不再为了饭店开车。

9月29日｜许昌 → 开封

08:30–09:00退房出发，约129km，预计10:30左右到开封。周二胖东来多数门店闭店，不再安排购物。

11:30｜午饭

可以选黄家老店中山路店（中山路中段34号），吃灌汤包等，之后去开封府比较顺；若酒店或停车位置不顺路，就不强求。

13:30–16:30｜开封府

成人票参考65元。下午挑2–3场演出即可，不用全追。

19:00｜西司夜市

晚饭直接去西司广场夜市，建议少量多样：羊肉炕馍、炒凉粉、杏仁茶、灌汤包、涮牛肚等。夜市通常18:30以后更热闹。

开封连续住两晚，优先万岁山—东京大道附近，免费停车和充电方便优先。

9月30日｜万岁山武侠城完整一天

07:45–08:00左右到景区。入园第一件事看当天节目单，优先锁定《三打祝家庄》《打铁花》等热门节目；必须以当天小程序预约规则为准。

午饭、晚饭都在园内解决，这天不要为了吃饭出园折腾。晚上玩到约21:30–22:00，回酒店后把车充到100%。

10月1日｜开封 → 临沂

06:00满电出发，约440km。国庆首日高速免费，但可能拥堵；按实时空桩安排2次快充，不固定死某一个服务区。

七、费用估算

原两人总预算仍按约5100–6100元估算，购物另算。教师资格证按人数节省：1人持证约再省95元，2人都持证约再省190元。洛阳、栾川、许昌酒店已有明确选择后，等你给实际订房价格再把总预算精确到几十元。

这版核心：景点不再加；住宿都按你确认的酒店走；龙门石窟停车和入口写死；餐馆只推荐顺路的，不为了吃饭折腾。
