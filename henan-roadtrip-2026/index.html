9/25周五

北京 → 洛阳只赶路，不安排景点

最累的一天，把体力全部留给驾驶和补能。

≈798km约4次快充住汉庭
06:00

北京满电出发

按150–180km一个补能观察点规划，单次20%–30%充到75%–85%更省时间。

全天

高速 + 快充

预计4次左右快充；午饭那次可以多充一点。遇到服务区排队就灵活换下一处。

19:30+

抵达洛阳

入住 汉庭酒店（洛阳市政府宝龙广场店）。当天不再追美食店，附近吃热饭、洗澡、休息。

9/26周六

洛阳龙门石窟 + 博物馆 + 应天门

洛阳核心日：早上石窟，下午博物馆可选，晚上看城楼夜景。

牛肉汤龙门石窟博物馆可选小街锅贴
06:40

早餐｜洛阳牛肉汤

推荐：兄弟俩老李家牛肉汤（洛龙店）
牛肉汤 + 饼丝/烧饼，可加一份牛肉。羊肉汤取消。
07:30

开车去龙门石窟

导航直接设：“龙门石窟西北服务区停车场”。假期如交警分流到东北服务区，服从现场分流，不逆行找西北。
08:00

龙门石窟｜从大石门 / 西山入口进

西北服务区停车 → 大石门 → 潜溪寺 → 宾阳三洞 → 摩崖三佛龛 → 万佛洞 → 莲花洞 → 奉先寺 / 卢舍那 → 古阳洞（体力允许）→ 西山南门 → 漫水桥 → 礼佛台

不专门爬东山。礼佛台拍完整西山全景后，询问工作人员当天返回西北服务区的电瓶车站点。景区以单向游览为主，奉先寺等重要内容要在出西山前拍完。

教师资格证 + 本人身份证：按现行政策可按45元半价票预算。
11:45

午饭 + 回酒店短休

午饭简单解决，12:30左右回汉庭休息一会儿。

14:20

洛阳博物馆｜预约成功才去

如果能约到9/26，就安排约1.5–2小时。重点看河洛文明、唐三彩、珍宝类代表性文物，不追求每个展厅全看。

约不上：直接把下午恢复成酒店午休，16:30左右再出门，不影响晚上。
17:20

晚饭｜西工小街锅贴

推荐：西工小街锅贴
锅贴 + 浆面条 / 馄饨 / 小米粥。允许稍微绕路，因为本身值得吃。
19:00

应天门夜景

应天门北广场 → 明堂天堂外围。还有体力再去洛邑古城 / 丽景门二选一。

9/27周日

洛阳 → 老君山 → 栾川完整山景日

两级索道换体力，把精力留给十里画屏和金顶亮灯。

两级索道十里画屏金顶夜景住山合友
07:00

洛阳满电出发

约150–170km，90%–100%电量出发，中途通常不用补电。

09:00

抵达老君山

停车、检票、准备冲锋衣/抓绒等保暖层。

09:30

两级索道 + 核心路线

一级索道 → 二级索道 → 十里画屏 → 马鬃岭 → 南天门 → 金顶道观群

一级索道往返约130元；二级往返约80元。你不想太累，建议都坐。

教师资格证 + 身份证：老君山门票按50元半价预算；索道无教师优惠。
15:30

山顶休息，等日落和亮灯

吃热食、补水、找地方坐着。9/26晚再次确认9/27当天亮灯及索道运营时间。

亮灯后

尽快下山 → 栾川山合友酒店

住 栾川山合友酒店（老君山凤凰天街店），滨河北路1号。酒店停车、充电方便。

晚饭首选：大有自在小馆
推荐栾川豆腐、橡子面饺、凉拌笋片；下山太晚就改凤凰天街其他本地菜。
9/28周一

栾川 → 开封老城慢逛 + 美食

上午赶路，下午按抵达时间慢逛，晚上吃西司夜市。

约350–400km预留1–2次快充鼓楼/书店街西司夜市开封住宿待定
08:00

山合友酒店满电出发

栾川直达开封，路程先按约350–400km规划。纯驾驶约4.5–5.5小时，另留补能、午饭和休息时间；以出发当天导航为准。

按原行程的补能节奏，预留1–2次快充。预计14:00左右抵达，路上延误就缩短下午散步。
途中

午饭与补能一起安排

中途吃简餐，不为赶开封午饭压缩休息。酒店位置确定后，再选择市区停车和充电点。

14:00+

抵达开封，入住或寄存行李

开封酒店待确定，连住9/28、9/29两晚；优先考虑停车、充电及往返万岁山方便。

14:30+

书店街 + 鼓楼周边

慢慢走、拍照、逛小店，不安排收费景点。若午饭没吃好且门店营业，可先吃邢家锅贴。

邢家锅贴老店：鲜肉韭黄锅贴、炒凉粉、桶子鸡按食量少量点，给夜市留胃口。
16:30

龙亭湖周边散步｜体力允许再去

以湖边、街景和古城氛围为主，不强制买龙亭景区门票。抵达较晚或爬山后仍累，就省略这段、回酒店休息。

18:30

西司广场夜市

小份多样：炒凉粉、杏仁茶、涮牛肚、灌汤包、四味菜。你不喜欢羊膻味，羊肉炕馍和羊汤跳过。
9/29周二

开封万岁山武侠城完整一天

只做一个大景点，把节目和夜场体验完整。

三打祝家庄打铁花夜场连住开封
07:45

到景区附近，按当日开放时间入园

提前查看9/29的营业时间和节目单，热门节目及预约规则以景区官方小程序当天公告为准。

万岁山由原9/30调整到9/29；如已买票或预约演出，先确认能否改期。不要直接沿用原日期的订单。
全天

围绕大型演出安排小节目

重点《三打祝家庄》《打铁花》，以当天实际排期为准。午饭晚饭都在园内解决，不出园折腾。

夜场后

离园 → 回开封酒店休息

当晚继续住开封，回酒店后尽早休息并把电补足。次日先开约130–150km到许昌，逛完胖东来后还要夜间返临沂。

9/30周三

开封 → 许昌 → 临沂白天购物，傍晚直接返程

许昌不住宿。把购物提前到上午和下午，争取17:00左右离开，预计跨入10月1日凌晨抵达临沂。

全天约630–700km返程预留约3次快充大众服饰时代广场许昌不住宿
07:30

开封退房，补好电后出发

开封到许昌约130–150km，按2小时左右驾驶时间规划，拥堵另计。导航到胖东来大众服饰附近合适的停车场，不再前往三国大酒店。

09:30

胖东来大众服饰

按门店实际开门时间进店，重点看鞋、男装、女装和服饰类商品，预留约2.5小时。若到得晚，缩短购物时间，给返程留余量。

12:00

午饭 + 坐下休息，顺便安排市区补能

附近吃午饭、坐下休息。提前查可用的公共快充和停车条件，尽量利用这段时间补足返程所需电量；以实际充电位置安排步行和购物顺序。

13:00

胖东来时代广场

百货、美妆、超市和自营商品预留约3小时，16:00左右结束购物。需要保质期较长的食品时，优先挑常温密封包装，并看生产日期和储存要求。

食品购买：即食熟食、烘焙按当天食量买；长途带走的商品按标签保存，需冷藏的食品要保证冷链。
16:00

早晚饭 + 出发前休息

吃饭、坐下休息、整理购物袋，备好饮水和途中简餐。核对电量与导航；中午没补够电就在许昌先补足，已充好则无需重复充电。

17:00

许昌直接出发回临沂

约500–550km，纯驾驶先按5.5–6.5小时粗估；加上快充和停车休息，返程按7–8小时起规划，拥堵和排队另计。无需再进开封市区。

当天合计约630–700km，还包含购物。这是较累的一天；出发前留足休息，困倦就找安全地点停车休息，不硬赶预计到达时间。
途中

按续航与空桩补电

返程预留约3次快充，根据电量、实际续航、空桩和排队情况调整。把补能、如厕和休息一起安排，不锁死具体服务区。

10/1
凌晨

00:00–01:00｜预计抵达临沂

这是9月30日晚返程的跨夜抵达时间，不再安排10月1日白天的驾驶或景点。若17:00以后才离开许昌，或途中堵车、排队、需要更多休息，抵达时间相应顺延。
